# Inspired by, not copied from

DocuLens is a clean-room educational implementation of document ingestion,
chunking, retrieval, evidence display, and abstention. The ideas are
informed by public documentation and user-facing concepts in:

- [RAGFlow](https://github.com/infiniflow/ragflow), Apache-2.0.
- [MLflow](https://github.com/mlflow/mlflow), Apache-2.0, for the emphasis on
  reproducible evaluation and inspectable runs.
- [GitHub licensing guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository).

No source code, branding, prompts, assets, or proprietary data were copied
from those projects. DocuLens is released under the MIT License.
